# Notification Sound

Place a notification sound file named `notification.mp3` in this directory.

The sound file should be:
- Format: MP3
- Duration: 1-2 seconds recommended
- Volume: Moderate level

You can download free notification sounds from:
- https://pixabay.com/sound-effects/search/notification/
- https://freesound.org/search/?q=notification
- https://mixkit.co/free-sound-effects/notification/

**Note:** For now, if no sound file is present, the app will use the default system notification sound.
