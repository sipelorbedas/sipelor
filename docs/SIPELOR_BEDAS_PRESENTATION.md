# 5️⃣ KEAMANAN SISTEM

## 🔒 Multi-Layer Security

### Authentication & Authorization

```
┌─────────────────────────────────────────────────┐
│  🔐  AUTHENTICATION                             │
├─────────────────────────────────────────────────┤
│                                                 │
│  • Email/Password authentication                │
│  • Email verification enforcement               │
│  • Google OAuth (Sign in with Google)           │
│  • Biometric login (Fingerprint/Face ID)        │
│  • Strong password requirements:                │
│    - Min 8 characters                           │
│    - Uppercase + lowercase                      │
│    - Numbers + special characters               │
│                                                 │
│  • Rate limiting (5 attempts / 15 min)          │
│  • Auto-logout after 15 min inactivity          │
│                                                 │
└─────────────────────────────────────────────────┘
```

### Data Protection

```
┌─────────────────────────────────────────────────┐
│  🛡️  DATA ENCRYPTION                            │
├─────────────────────────────────────────────────┤
│                                                 │
│  Encryption at Rest:                            │
│  • AES-256 encryption untuk data sensitif       │
│  • flutter_secure_storage untuk credentials     │
│  • Encrypted file storage                       │
│                                                 │
│  Encryption in Transit:                         │
│  • HTTPS/TLS untuk semua komunikasi             │
│  • SSL Certificate Pinning                      │
│  • WebSocket Secure (WSS) untuk realtime        │
│                                                 │
│  Password Security:                             │
│  • Bcrypt hashing via Supabase Auth             │
│  • Never stored in plaintext                    │
│  • Secure password reset flow                   │
│                                                 │
└─────────────────────────────────────────────────┘
```
